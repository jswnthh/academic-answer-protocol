# Mark-wise Answer Rules

The self-contained student entry point is [`../AGP.md`](../AGP.md). This file is an educator-maintained explanation of mark-wise expectations.

| Marks | Core output | Special cases |
|---|---|---|
| 2 | Exactly two concise, meaningful bullets | Two definitions: one bullet each; short numerical work inside two bullets |
| 5 | Definition, organized key points, relevant method/diagram reference | Show tables and full working for calculations |
| 10 | Definition, developed explanation, method/working, result or interpretation | Address every subpart; show all intermediate calculations |

Use the **subject's actual rubric** whenever available; these are defaults, not universal mark distributions. For conceptual diagrams, reference the appropriate textbook diagram without ASCII reproduction. For computational Gantt charts, show the required process execution order and timing clearly.
